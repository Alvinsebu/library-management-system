# API Guide

## REST Endpoints

### Authentication

- `POST /auth/signup`
  - Registers a new user.
  - Body: `SignupRequest(email, password, name)`.
  - Returns: `ApiResponse` with success status and message.

- `POST /auth/login`
  - Authenticates a user and returns a JWT token.
  - Body: `LoginRequest(email, password)`.
  - Returns: `ApiResponse` containing `JwtResponse(token, email, userId, expiresIn)`.

### Book Management

- `GET /books`
  - Lists all books.
  - Requires bearer token.

- `GET /books/borrowed`
  - Lists books currently borrowed by the authenticated user.
  - Requires bearer token.

- `POST /books/borrow/{bookId}`
  - Borrows a book for the authenticated user.
  - Requires bearer token.

- `POST /books/return/{bookId}`
  - Returns a borrowed book.
  - Requires bearer token.

- `POST /books/create`
  - Creates a new book record.
  - Body: `BookRequest(title, author, description, copiesAvailable)`.
  - Requires bearer token.

## gRPC

- Proto file: `src/main/proto/book_service.proto`
- gRPC service available on port configured by `grpc.port` in `application.yml`.

## Security

- Use `Authorization: Bearer <token>` header for protected endpoints.
- JWT tokens are generated by `AuthService` and validated by `JwtAuthenticationFilter`.
